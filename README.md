# Кыргызский синтезатор речи

Веб-приложение для озвучивания кыргызского текста. FastAPI загружает модель
`facebook/mms-tts-kir`, а интерфейс доступен на той же странице.

## Развертывание на Render

1. Войдите в [Render](https://render.com/) и выберите **New → Blueprint**.
2. Подключите GitHub-репозиторий `copilooty/kyrgyz-synthesizer`.
3. Render прочитает `render.yaml`; проверьте настройки и создайте сервис.
4. После первого запуска откройте выданный Render URL. Первая сборка и запуск
   могут занять несколько минут, пока устанавливаются PyTorch и модель.

В конфигурации задан платный план `standard`, один worker и CPU-версия PyTorch.
Модель загружается из Hugging Face при старте. Нужен план с достаточной памятью
для PyTorch и модели; если сервис завершает запуск из-за нехватки памяти,
выберите более мощный план.

## Локальный запуск

Нужен Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Модель скачивается при первом запуске.
